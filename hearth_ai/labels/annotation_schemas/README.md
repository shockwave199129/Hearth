# Annotation schemas (Phase B)

JSON Schema contracts for Memory / Relationship / Strategy labels when humans
or LLMs annotate conversation turns. Prepared JSONL from
`data/prepare/prepare_{memory,relationship,strategy}.py` must match these.

| Schema | Head | Train loss |
|---|---|---|
| [memory.schema.json](memory.schema.json) | MemoryHead | MemoryLoss (store BCE + type CE + importance BCE) |
| [relationship.schema.json](relationship.schema.json) | RelationshipHead | SmoothL1 on 4 floats |
| [strategy.schema.json](strategy.schema.json) | StrategyHead | CrossEntropy |

## LLM annotation prompt sketch

```
You label one user turn for a supportive companion.
Return ONLY JSON matching the schema for {memory|relationship|strategy}.
Do not invent clinical diagnoses. Prefer conservative store=0 and listen/validate
strategies when unsure. Use defer_safety only for clear crisis language.
```

Synthetic seed data (no LLM required) is generated by the prepare scripts for
local training smoke tests.
