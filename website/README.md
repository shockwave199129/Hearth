# Hearth website

Astro product site deployed to GitHub Pages.

```bash
cd website
npm install
npm run dev      # http://localhost:4321/Hearth/
npm run build
npm run preview
```

Brand images are copied from repo-root `assets/` into `public/brand/` on
`dev` / `build` via `scripts/sync-assets.mjs`.

Production URL: https://shockwave199129.github.io/Hearth/
